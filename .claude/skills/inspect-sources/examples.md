# Evidence from Rastro

## Electricity, 2026-10-22

See `docs/experiments/electricity/inspection.md`, `source-profile.json`, `profile.py` and `inspection-time.yaml`.
This inspection happened before the skill existed; it is motivating evidence, not a run performed with this skill.

- A generation CSV modified in 2026 contained observations ending in February 2020.
- The annual workbook mixed overview GWh with detailed MWh and introduced market partitions in 2025. A machine/month
  key was insufficient for those records.
- Most MEM registry entries cited CAMMESA, so changing publisher did not create independent generation evidence.
- Company portfolio aliases and operator/ownership roles required evidence beyond equal names.
- Catalog license declarations did not settle reuse terms for a separately hosted workbook.

These are examples of what to inspect, not requirements to use these sources, periods, units or candidate questions.
