# Source inspection and reuse

Scope: user-authorized read-only thesis reproduction. Inspection began on 2026-10-25 UTC (2026-10-24 in Argentina); times are in the receipts. Human effort was not separately measured. No new domain, semantic mapping or app module is being approved by this inspection.

- Publisher: Argentina's Secretaría de Energía. Public nonconventional-production resource `b5b58cdc-9e07-41f9-b392-fb9ec68b0725`, in the existing Capítulo IV package. Official HTTPS download; the catalog URL uses HTTP. Catalog metadata accessed during this run identifies CC-BY-4.0, 148,923,474 bytes, modified 2026-10-22. The endpoint is mutable; the download is fingerprinted in the input receipt. Raw production, metadata and the supplied PDF stay under ignored `data/raw/gas-thesis/`.
- Grain: a production declaration for a well/month, potentially multiple source rows. `idpozo` joins the existing registry and fracture records; `idpo` joins trajectories. Sum production by well/month before Q12, sum fracture treatments per well, and select the longest trajectory before joining. Context comes from the first positive-gas month. These choices are explicit replay assumptions where the PDF lacks implementation details.
- Observation period: the new file includes history before 2018 and observations beyond March 2026. The replay applies the thesis's March 2026 observation cutoff; the publisher snapshot itself is newer. Actual rows, wells, filter/join losses, target trimming and missingness are in `input-receipt.json`. An accessible catalog alone was not counted as data access.
- Units: production `prod_gas` is in thousand m³, as stated in PDF p. 25. The thesis's result table uses an m³ label with values consistent with unconverted source sums. The replay keeps source-unit numeric targets, converts MAE to million m³ separately, and flags the ambiguity rather than silently equating them.
- Other sources: reuse the currently loaded public CSV snapshots for registry, fracture and trajectory, each fingerprinted. They are refreshed versions, not the thesis's historical snapshots. All four sources share one publisher and are not independent evidence. The PDF is a methodological reference, not an independent per-well target reference.
- Identity limits: join by the publisher's well ID, not a fuzzy name match. Source duplicates and multiple fracture/trajectory rows are resolved at their own grain before integration. Full filter/join counts document coverage; no goal of obtaining exactly 642 wells controls inclusion.
- Semantic layer: reuse the existing Well, MonthlyGas, WellStart, Fracturing and trajectory concepts and `gasFirst12Months` meaning. This replay operates on isolated files and proposes no additional classes, properties, mappings or production load. A future model integration would need to preserve record-level provenance for any added derived inputs.

Recommendation: suitable for a **current-snapshot, PDF-guided partial replay**, conditional for exact reproduction until original code, well IDs, geology-calibration coefficients and frozen source versions are available. The user-provided PDF resolves the previous primary-document access blocker; it does not supply the original executable implementation.
