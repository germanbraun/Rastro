La comparación honesta. Sin integración, el SQL directo inventa cómo reconocer un fármaco en cada consulta: acierta 18 y cambia de respuesta según cómo se pregunte. Si al SQL le damos las tablas de enlaces de Rastro, acierta todo y es consistente: la precisión viene de integrar una vez. Lo que agrega la capa semántica es el resto: el conocimiento de cada fuente queda en los mapeos y no en cada consulta, cada dato trae su fuente, y se puede consultar junto con datos de otras organizaciones. Una capa de vistas SQL bien hecha resolvería parte de esto; la capa semántica lo hace con estándares y suma procedencia y datos de afuera.
