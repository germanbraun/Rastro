Why now

Three changes make integrating once worth more

AI already queries the data

It answers fast, but without shared definitions each assistant picks its own. With a business dictionary, it asks by concept and cites the source.

Sources change often

New versions, renamed columns, other units. If the integration lives in every query, every change is fixed many times.

Models have to explain themselves

A number without evidence cannot be audited or defended. With Rastro, every prediction says where each value comes from.

What gets built stays in open standards: it belongs to the company and does not need Rastro to be read.

What to say (45 seconds): integrating data is not a new problem; what is new is what it costs not to solve it. First, teams already use AI assistants to query their data: without a common dictionary, each one defines «YPF's production» its own way and nobody knows where the number comes from. Second, sources change all the time, and if every query, dashboard and model solves the integration on its own, every change is fixed many times. Third, when a model decides something, someone asks why: Rastro returns the evidence. And what gets built stays in open standards, so there is no lock-in to us.
