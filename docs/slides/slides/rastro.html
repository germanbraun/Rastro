Rastro es una capa semántica: se pone entre las fuentes y quien pregunta, y traduce el lenguaje de negocio al de las tablas. Tiene tres piezas: la ontología, que define los conceptos; los mapeos, que conectan cada concepto con las columnas de cada fuente; y los enlaces revisados, que unen ensayos con fármacos. El LLM nunca ve tablas: lee la ontología y pregunta en esos conceptos. Técnicamente es un grafo de conocimiento virtual: Ontop traduce cada pregunta a SQL sobre las fuentes.
