Para repetir la muestra:

```sql
SELECT setseed(0.42);
SELECT x.rule, x.intervention, x.matched, m.pref_name
FROM (
  SELECT DISTINCT ON (d.id, d.family) d.rule, i.name AS intervention, d.matched, d.family
  FROM linking.intervention_drug d JOIN linking.intervention i ON i.id = d.id
) x
JOIN chembl.molecule_dictionary m ON m.chembl_id = x.family
ORDER BY random()
LIMIT 100;
```
